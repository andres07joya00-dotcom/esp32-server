SISTEMA INTEGRADO DE GESTION Y MONITOREO AGROAMBIENTAL
Invernadero Inteligente IoT

🎯 Objetivo

Diseñar y construir un invernadero automatizado que permita controlar variables ambientales como la temperatura, la humedad y la iluminación, con el fin de optimizar el crecimiento de las plantas y mejorar la producción en un entorno educativo y sostenible.

🔧 Metodología

Se diseñó el sistema definiendo las variables a controlar y el esquema del invernadero. Se construyó la estructura física y se instaló el sistema electrónico con sensores y actuadores conectados a un microcontrolador ESP32 DFRobot. Se programó la automatización completa y se realizaron pruebas exhaustivas para optimizar el funcionamiento.

📋 Materiales

🏗️ Estructura Física

  • Tubos de PVC
  • Palos de balso
  • Plástico transparente (polietileno)
  • Cable de acero galvanizado

⚡ Sistema Electrónico

  • Microcontrolador ESP32 DFRobot
  • Sensor temperatura y humedad
  • Sensor de humedad del suelo
  • Módulo relé
  • Cables y protoboard

🎮 Actuadores

  • Bomba de agua
  • Ventilador
  • Luces LED grow

🤖 Funcionamiento Automático

Sistema inteligente IoT que monitorea constantemente y actúa automáticamente:

🌡️ Temperatura Alta

→ VENTILADOR ON

💧 Suelo Seco

→ BOMBA DE RIEGO ON

💡 Baja Luminosidad

→ LEDs GROW ON

✨ Control total vía app IoT + Mantenimiento autónomo 24/7
